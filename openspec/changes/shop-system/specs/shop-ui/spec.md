## ADDED Requirements

### Requirement: ShopUI 창 열기/닫기
시스템 SHALL `B` 키로 ShopUI 창을 토글할 수 있어야 한다.

#### Scenario: B 키로 Shop 열기
- **WHEN** 플레이어가 `B` 키를 누르면
- **THEN** ShopUI 창이 활성화되고 마우스 커서가 잠금 해제되며 커서가 보인다

#### Scenario: B 키로 Shop 닫기
- **WHEN** ShopUI가 열린 상태에서 `B` 키 또는 닫기(X) 버튼을 누르면
- **THEN** ShopUI 창이 비활성화되고 마우스 커서가 잠기며 커서가 숨겨진다

### Requirement: 카테고리 탭 전환
시스템 SHALL 상단에 [낚싯대] [미끼] [물고기 판매] 탭을 표시하고 전환 가능해야 한다.

#### Scenario: 낚싯대 탭 선택
- **WHEN** [낚싯대] 탭을 클릭하면
- **THEN** 아이템 리스트에 모든 RodDataSO 목록이 표시된다

#### Scenario: 미끼 탭 선택
- **WHEN** [미끼] 탭을 클릭하면
- **THEN** 아이템 리스트에 모든 BaitDataSO 목록이 표시된다

#### Scenario: 물고기 판매 탭 선택
- **WHEN** [물고기 판매] 탭을 클릭하면
- **THEN** 하단 인벤토리 패널이 활성화되고 보유한 물고기 목록이 표시된다

### Requirement: 아이템 리스트 표시
시스템 SHALL 선택한 카테고리의 아이템을 스크롤 가능한 리스트로 표시한다.

#### Scenario: 아이템 슬롯 표시
- **WHEN** 카테고리가 선택되면
- **THEN** 각 아이템은 아이콘, 이름, 등급(별표), 가격을 포함한 슬롯으로 표시된다

#### Scenario: 소유 상태 표시
- **WHEN** 아이템을 이미 소유하고 있으면
- **THEN** 슬롯에 "소유함" 또는 "장착 중" 배지가 표시되고 구매 버튼이 비활성화된다

### Requirement: 아이템 상세 정보 패널
시스템 SHALL 아이템 선택 시 우측에 상세 정보 패널을 표시한다.

#### Scenario: 아이템 선택
- **WHEN** 아이템 리스트의 슬롯을 클릭하면
- **THEN** 우측 상세 패널에 아이콘(크게), 이름, 등급, 가격, 설명, 스탯 정보가 표시된다

#### Scenario: 구매 버튼 (미소유)
- **WHEN** 미소유 아이템을 선택하고 보유 골드가 price 이상이면
- **THEN** [구매] 버튼이 활성화되어 표시된다

#### Scenario: 구매 불가 (골드 부족)
- **WHEN** 미소유 아이템을 선택하고 보유 골드가 price 미만이면
- **THEN** [구매] 버튼이 비활성화되고 "골드 부족" 메시지가 표시된다

#### Scenario: 장착 버튼 (소유)
- **WHEN** 소유한 아이템을 선택하면
- **THEN** [장착] 버튼이 표시되고 (이미 장착 중이면 [장착 해제] 버튼이 표시된다)

### Requirement: 아이템 구매
시스템 SHALL 사용자가 골드로 아이템을 구매할 수 있어야 한다.

#### Scenario: 구매 성공
- **WHEN** [구매] 버튼을 클릭하고 서버가 유효성을 검증하면
- **THEN** 골드가 차감되고 아이템이 소유 목록에 추가되며 NotificationUI로 "구매 완료" 메시지가 표시된다

#### Scenario: 구매 실패 (골드 부족)
- **WHEN** 서버에서 골드가 부족함을 확인하면
- **THEN** 구매가 거부되고 "골드가 부족합니다" 메시지가 표시된다

### Requirement: 골드 표시
시스템 SHALL ShopUI 상단에 현재 보유 골드를 항상 표시한다.

#### Scenario: 골드 업데이트
- **WHEN** 구매/판매 후 OnDataChanged 이벤트가 발생하면
- **THEN** 상단 골드 텍스트가 업데이트된 값으로 즉시 갱신된다
